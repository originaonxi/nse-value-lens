        03 / READ THE LABELS

        A state is a condition.
        Execution is a separate step.

        The buy condition is a fresh closing cross above the last confirmed high, with two rising highs and lows. The Nifty filter and price, liquidity and volatility screens must pass.

        A paper entry uses only the next session's open within one ATR of the signal close. The initial stop is two signal-day ATR below the actual entry. There is no fixed profit target in this rule.

        Full classification rules and data notes

        BUYFresh qualifying breakout. Existing positions and allocation limits still need checking.

        SELLClose below the confirmed swing low. An existing stop or the 10-session limit can require an earlier exit.

        WATCHRising structure. The band below resistance is a reference zone; wait for a fresh closing breakout.

        CAUTIONEntry is blocked, the breakout is no longer fresh, or data is incomplete.

        AVOIDNo qualifying structure or the price, turnover or volatility screen fails.
